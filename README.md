## 🚀 วิธีการนำขึ้น GitHub และเปิดใช้งาน GitHub Pages (เพื่อเปิดกล้อง AR ได้ 100%)

เนื่องจากเว็บเบราว์เซอร์ยุคใหม่มีข้อกำหนดความปลอดภัยที่เข้มงวด การรันผ่าน **GitHub Pages** จะทำให้เบราว์เซอร์สามารถ **ขออนุญาตเปิดกล้อง (Allow Camera) และเปิดกล้อง AR ส่องโต๊ะจริงในห้องเรียนได้ทันที** โดยคะแนนทั้งหมดจะยังคงส่งเข้า Google Sheet ของคุณครูตามปกติ

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าเว็บไซต์ [GitHub.com](https://github.com) และเข้าสู่ระบบ
2. กดปุ่ม **New** (หรือเครื่องหมาย `+` มุมขวาบน) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น: `salted-egg-ar`
4. เลือกเป็น **Public**
5. กดปุ่ม **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์ขึ้น GitHub
1. ในหน้า Repository ที่เพิ่งสร้าง ให้คลิกปุ่ม **uploading an existing file**
2. ลากไฟล์เหล่านี้จากโฟลเดอร์ `d:\ระบบ\Game` ขึ้นไป:
   - `index.html` (ไฟล์หลักของเกม สำคัญที่สุด)
   - `README.md`
   - `.gitignore`
   *(ไฟล์ `รหัส.js` เป็นโค้ดบน Google Apps Script จะอัปโหลดเก็บเป็นประวัติไว้ด้วยก็ได้ครับ)*
3. เลื่อนลงมาด้านล่าง กดปุ่มเขียว **Commit changes**

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages (ขั้นตอนสุดท้าย)
1. ในหน้า Repository ของคุณครู ให้คลิกแท็บ **Settings** (รูปฟันเฟืองด้านบน)
2. แถบเมนูด้านซ้าย ให้คลิกที่ **Pages**
3. ตรงส่วน **Branch**:
   - เปลี่ยนจาก `None` เป็น `main` (หรือ `master`)
   - โฟลเดอร์เลือกเป็น `/ (root)`
4. กดปุ่ม **Save**
5. รอประมาณ 30-60 วินาที ระบบจะสร้างลิงก์เว็บไซต์ให้ เช่น:
   `https://<username>.github.io/salted-egg-ar/`
